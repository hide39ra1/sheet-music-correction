# 譜面補正

スキャンしたPDFや画像フォルダの傾きと上下を、PC内で補正します。

## 起動

Python 3.10以上と Poppler の `pdfinfo`・`pdftoppm` が必要です。Poppler の実行ファイルを PATH に追加してください。

```powershell
python -m pip install -r requirements.txt
python app.py
```

ブラウザで http://127.0.0.1:8765 を開きます。画像フォルダの保存には Edge または Chrome を使用してください。停止するには起動した端末で Ctrl+C を押します。

## 使い方

1. PDFまたは画像フォルダを選びます。画像はフォルダ内の相対パスを自然順で並べます。
2. 偶数ページの180°回転と検出された傾きを確認します。角度や上下はページごとに変更できます。
3. 「補正結果を保存」を押します。フォルダの場合は選択した保存先の下に新しいフォルダを作ります。

PDFは300 dpiの画像として書き出し、表示上のページ寸法を維持します。検索可能な文字や注釈の編集情報は画像化されます。画像はファイル名・拡張子・ピクセル寸法を維持します。JPEG、PNG、単一フレームのTIFF、BMP、WebPに対応します。既定では回転した画像を縮小して端の欠けを防ぎます。

処理はローカルで完結します。Gitの追跡対象はプログラムの明示的なファイル一覧に限定しています。
